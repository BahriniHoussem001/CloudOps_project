# CloudOps Service Platform

CloudOps Service Platform is a cloud-native DevOps and DevSecOps project built to simulate a professional deployment environment for a modular web application.

The project combines software development, infrastructure automation, CI/CD, GitOps, security automation, Kubernetes deployment, monitoring, logging, and cloud engineering practices.

## Main Goals

- Build a modular web application using ASP.NET Core and React
- Containerize the application with Docker
- Deploy the system on Kubernetes
- Automate infrastructure using Terraform
- Build CI/CD pipelines with Jenkins
- Apply GitOps using Argo CD
- Integrate DevSecOps security checks
- Monitor the platform using Prometheus, Grafana and Loki

## Tech Stack

- Backend: ASP.NET Core Web API
- Frontend: React.js
- Databases: PostgreSQL, MongoDB, Redis
- Messaging: RabbitMQ
- Containerization: Docker
- Orchestration: Kubernetes
- CI/CD: Jenkins
- GitOps: Argo CD
- IaC: Terraform
- Security: SonarQube, Trivy, Gitleaks, Checkov
- Monitoring: Prometheus, Grafana, Loki
